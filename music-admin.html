Music Catalog Manager

Prepare song titles, artists, album details, cover art and audio URLs for the shared Orbit X Music catalog.

Publishing: This tool creates a music-catalog.json file; it does not upload audio or publish automatically. Export the JSON and replace that file in GitHub. Only use music and artwork you own or have permission to distribute. Use direct HTTPS media URLs.

How to publish

  1. Upload the audio and cover to a storage host and copy direct HTTPS links.
  2. Add each track here with complete metadata.
  3. Click Export music-catalog.json.
  4. In the Orbit X GitHub repository, replace music-catalog.json with the downloaded file and commit it.
  5. Open Orbit X Music to test audio, artwork, search and playlists.
